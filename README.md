# Mano-Infra-datacenter-power-analysis
Datacenter Power &amp; Cooling Performance Analysis — PUE, WUE, Anomaly Detection | Python · SQL · Power 

## Overview
End-to-end data analysis project simulating a hyperscale 
datacenter environment — directly aligned with xAI 
Physical Infrastructure Data Analyst requirements.

## Key Results
- Analysed 8,760 hours of sensor data across 12 months
- Average PUE: 1.535 (industry target < 1.5)
- Detected 50 anomalous hours concentrated in Jun–Aug
- Identified $130K in potential annual savings
- Built executive-grade Power BI dashboard

## Tools Used
- Python (Pandas, Matplotlib, NumPy)
- SQL (anomaly detection, cost analysis, PUE trends)
- Power BI (executive dashboard)
